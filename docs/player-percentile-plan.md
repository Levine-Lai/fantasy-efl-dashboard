# 球员百分位横条：按位置的指标预览

初版方案保留在下方供参考。现已上线“个人数据”档案模块，点击场均表球员姓名或顶部导航进入。实际指标以用户最新清单及页面为准，后卫/中场抢断和拦截使用 Statz 原始累计，避免将官方不记录的动作误作零。

| 位置 | 现有数据可计算 | 新数据源可接入（尚未上线） |
| --- | --- | --- |
| 门将 | 扑救/90、扑救率、零封率、失球/90（低优）、场均Fantasy得分 | 扑球出击/90等原始动作可调查；预期扑救/PSxG不作为已确认可用项 |
| 后卫 | 解围/90、封堵/90、抢断/90、拦截/90、零封率、进球+助攻/90、场均Fantasy得分 | 争顶成功次数/90、对抗成功率、传球成功率、被过/90（低优） |
| 中场 | 关键传球/90、拦截/90、抢断/90、射正/90、xG/90、进球+助攻/90、场均Fantasy得分 | 创造大机会/90、成功过人/90、传球成功率、对抗成功率 |
| 前锋 | xG/90、进球/90、射正/90、进球+助攻/90、场均Fantasy得分 | 射门/90、射门转化率、单次射门xG、成功过人/90、创造大机会/90 |

计数动作推荐用每90分钟比较；扑救率、零封率、成功率按百分比。单次射门xG和转化率需另设射门次数门槛。扑点数据太稀疏，可作为补充事实，不作为主要能力条。预期得分为现有模型估计，应与历史表现分组，不能叫EPM。

## 数据范围与可靠性

- 官方 Fantasy EFL 已完成且确认的比赛统计可计算已有项；xG 来自现有 Statz 快照。
- 2026-10-15 额外核查 Statz playerRows：英冠573人、英甲547人、英乙546人，共1666人。传球、成功传球、创造机会/大机会、过人/成功过人、总对抗/成功对抗、争顶成功次数等字段可读；xa 三联赛均无非空值，暂不接入xA。
- 来源：https://statz.ai/competitions/league-two/stats/players?group=defending 、https://statz.ai/competitions/league-two/stats/players?group=attacking 及另两联赛对应路径。
- 数据字段非空不自动证明每场覆盖完整，正式接入需核对样本、零值含义、赛季和更新时间。
- 同一指标用同一来源的分子/分母。官方与第三方统计可能有差异，不能随意混用或平均。

## 横条呈现与比较口径

- 球员选择、球队筛选用于找到个人；球队筛选不缩小联赛百分位参照组。
- 保留7种联赛组合、同位置/全体适用球员比较，默认同位置。
- 提供至少450/900分钟门槛，推荐900分钟；每个指标独立排除缺失值及零分母。
- 单条显示：指标名、百分位条、原始数值、名次/有效人数、来源。失球、被过等低优指标反向。
- 按未舍入数值计算排名与百分位，显示时再舍入；并列采用相同竞争名次与平均百分位。
- 高优指标百分位：100 × (N−1−更高人数−(并列人数−1)/2)/(N−1)。N不足时显示样本不足，不制造精确排名。
- 原始表格按用户要求显示0.0，不据此把未来画像中的缺失数据作为实测零参与排名。

## 当前快照示例

英乙后卫、至少450分钟：Fitzwater 场均解围15.2，1/99、百分位100；场均Fantasy得分10.1，2/99、约99百分位；场均封堵1.6，并列3/99、约97百分位。排名描述历史相对表现，解围次数也受球队被压制程度影响。
