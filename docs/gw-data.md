# GW 浏览与数据口径

- 表头统一选择赛季 GW；URL `?gw=9` 可刷新、分享，并随球员链接进入个人档案。默认进入官方 `playing` 轮次，否则进入最近待赛轮次。
- 历史轮次：用官方 `live_scores/{id}.json` 重建本轮实际 Fantasy 积分、回顾阵容与球队榜。仅纳入 `completed && isFinalized` 的比赛，按球员/球队与比赛 ID 去重，双赛积分相加。
- 历史场均表、散点图和个人档案：按所选 GW 及之前的 GW 归属累计官方已结算比赛。它是根据最新官方结果重建的数据，含官方后续修正，不是当时保存的赛前快照。历史 xG、扩展统计、持有率、联赛排名没有存档，不用当前值倒填。
- 当前和未来轮次：共用最新已结算统计，按各轮剩余有效赛程分别计算预测。当前轮已经结算的比赛也可进入模型样本；已经完赛、延期、取消的比赛不再贡献剩余预期得分。未来较远轮次只是根据当前球员状态和样本推演，不能视为未来阵容确认。
- 赛程：北京时间按日期和开球时间分组，展示比分、待赛/进行中/待结算/已结算状态。球队在本 GW 的有效比赛数超过一场即标 `×2`（更多场则显示实际数量）。延期、取消不计入双赛；已完成的有效场次仍计入该轮总赛程。提供联赛组合与只看双赛筛选。
- 官方当前有 39 个常规 GW，另有附加赛首回合、次回合、决赛三个阶段。附加赛未公布的赛程与截止时间显示待公布，不虚构对阵或预测。
- 构建每天北京时间 08:17 触发（GitHub 定时可能延迟），推送和手动构建也触发更新。每次构建共用一份官方球员、球队、轮次数据，并限并发读取已结算轮次，避免为每个预测 GW 重复请求接口。
- 浏览器首屏只带当前/下一轮与最新累计统计；整季轮次索引很小。其他轮次使用独立带内容哈希的 JSON，选中后加载并在当前页面缓存。历史 JSON 包含累计统计，未来 JSON 复用首屏统计。加载失败可重试，旧内容暂时禁用，快速切换时忽略较早请求的返回。

验证：`node scripts/test-round-views.mjs`，覆盖所有轮次、双赛、未结算排除、重复行、历史样本隔离、历史缺失数据与空赛程；另做浏览器端手机/桌面切换和个人档案联动检查。
