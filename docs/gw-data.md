# GW 浏览与数据口径

- 表头统一选择赛季 GW；URL `?gw=9` 可刷新、分享，并随球员链接进入个人档案。默认进入官方 `playing` 轮次，否则进入最近待赛轮次。
- 历史轮次：用官方 `live_scores/{id}.json` 重建本轮实际 Fantasy 积分、回顾阵容与球队榜。仅纳入 `completed && isFinalized` 的比赛，按球员/球队与比赛 ID 去重，双赛积分相加。
- 历史场均表、散点图和个人档案：按所选 GW 及之前的 GW 归属累计官方已结算比赛。它是根据最新官方结果重建的数据，含官方后续修正，不是当时保存的赛前快照。历史 xG、扩展统计、持有率、联赛排名没有存档，不用当前值倒填。
- 当前和未来轮次：共用最新已结算统计，按各轮剩余有效赛程分别计算预测。当前轮已经结算的比赛也可进入模型样本；已经完赛、延期、取消的比赛不再贡献剩余预期得分。未来较远轮次只是根据当前球员状态和样本推演，不能视为未来阵容确认。
- 赛程：改为球队 × GW 的 FDR 矩阵，只展示表头所选的一个 GW。对手卡片展示队徽、完整短队名、主/客、模型预期进球与失球、进攻/防守难度，不显示比分与开球时间。默认按剩余赛程的综合机会指数降序（容易在前），双赛取平均而非加总，缺失评级或无剩余赛程放最后；切换攻防着色不改变综合排序。双赛在同一格分别列对手并逐场着色，延期、取消不计入；提供联赛组合、球队搜索与本轮双赛筛选。
- 官方当前有 39 个常规 GW，另有附加赛首回合、次回合、决赛三个阶段。附加赛未公布的赛程与截止时间显示待公布，不虚构对阵或预测。
- 构建每天北京时间 08:17 触发（GitHub 定时可能延迟），推送和手动构建也触发更新。每次构建共用一份官方球员、球队、轮次数据，并限并发读取已结算轮次，避免为每个预测 GW 重复请求接口。
- 浏览器首屏只带当前/下一轮与最新累计统计；整季轮次索引很小。其他轮次使用独立带内容哈希的 JSON，选中后加载并在当前页面缓存。历史 JSON 包含累计统计，未来 JSON 复用首屏统计。加载失败可重试，旧内容暂时禁用，快速切换时忽略较早请求的返回。

验证：`node scripts/test-round-views.mjs`，覆盖所有轮次、双赛、未结算排除、重复行、历史样本隔离、历史缺失数据与空赛程；另做浏览器端手机/桌面切换和个人档案联动检查。

## 攻防 FDR（初始模型，尚未回测校准）

- Statz 数据为赛季 xG/场与 xGA/场，并增加同一页面公开的 `home`、`away` 分项；它们不是 Statz 提供的现成 FDR。归一化后的进攻指数 `100 × 平滑xG / 联赛均值`，防守指数 `100 × 联赛均值 / 平滑xGA`，均为越高越强。
- 总体场均向同联赛加权均值收缩 8 场；主客场分项向总体实力 × 联赛主客场系数再收缩 8 场。缺失分项回到总体实力与联赛系数，缺失总体不评级。这里的 8 场是保守初始先验，不是优化回测所得。
- `λ进 = 己方该场地进攻率 × 对手对应场地失球率 / 联赛对应场地进球均值`；`λ失 = 对手进攻率 × 己方失球率 / 联赛对应均值`。主客场由已抓取的联赛分项自然反映，不叠加另一个固定主场加成。
- `攻 = ln(λ进/μ)`；`防 = ln(μ/λ失)`；`综合 = 0.5×攻 + 0.5×防`。各信号转换为 `50+50×tanh(信号/0.55)` 的 0–100 机会指数；70/58/42/30 为五档分界，1容易、5困难。0.55 与分档是显示尺度，未校准成胜率或得分概率。
- 颜色描述己方面对该对手的机会；同一对手对不同球队可有不同颜色。对手弱防但强攻时，进攻分项易、防守分项难，综合可能居中。综合、进攻、防守可独立切换，点击对手查看 λ进/λ失、双方指数及样本数。
- 不用比赛数量降低难度；双赛两个对手各自着色。已赛没有赛前快照，呈灰色，不用当前 xG 倒填历史。
- 精简赛程矩阵文件单独生成，接近该区域时才加载并缓存。没有比分、日期、事件等冗余字段，不为显示三轮赛程下载三份完整预测文件。
- `node scripts/test-fixture-difficulty.mjs` 检查强攻弱防抵消、己方攻防变化、样本收缩、主客视角互换一致、缺失数据、72支球队匹配及轻量载荷。


## 球队预期得分（合并赛程版）
球队选择与单 GW 赛程合并。左侧队徽和总预期得分，右侧逐场对手、主客场、单场预期得分和攻防着色；原联赛排名、近五场及汇总 xG 文本移除。按未四舍五入的本轮总预期得分降序，双赛相加。
使用 fixture-difficulty 的主客场收缩 xG/xGA 作为独立泊松进球分布均值：E(points)=5P(win)+3P(draw)+2P(away win)+2P(clean sheet)+2P(goals>=2)+2P(goals>=4)。官方已结算球队结果生成时逐条验证计分规则。当前轮仅预测未完成比赛，历史轮按官方实际积分排序，不回填今日预测。缺失指标保留对阵、分数显示空缺且排后。上方推荐球队也使用同一模型。
这是真实计分事件的数学期望，替代旧任意加权推荐指数。未做样本外校准，不纳入个人已用球队次数；进攻/防守切换只改变颜色，不改变得分排序。


### 赛程解析布局
桌面（>900px）限制主体最大宽度 1160px，左侧紧凑列表，右侧 300–340px 对阵解析；单赛格子保持与双赛的单格同宽。解析含计分事件概率及预期贡献、xG/xGA 和双方实力指数。≤900px 隐藏侧栏，解析直接展开在选中球队行之后。筛选改变时清除选中对阵，重复点击可收起。预测计算及排序保持一致。


### 单侧机会排序与球员球队筛选
赛程“综合”按预期得分之和排序；“进攻”按进攻机会指数降序，忽略己方防守与对手进攻；“防守”按防守机会指数降序，忽略己方进攻与对手防守。指数已含主客场与样本收缩。双赛单侧指数取平均，缺失排后；左列显示对应指数及总预期得分，历史无快照禁用单侧模式。
球员场均数据新增带队徽的球队筛选，与搜索、位置、至少出场条件叠加；联赛切换时重置为全部球队，选项随联赛变化。热图仍以同联赛同位置为比较样本，不因只选某球队而改变百分位。


### 可视化近期比赛窗口
新增最近1/3/7场及全部。独立的哈希版本逐场 JSON 仅在首次切换短期窗口时加载，去重并仅收录官方确认完赛、球员出场分钟>0的记录。截止到所选GW归属范围，按实际比赛时间倒序取每个对象最近N场，双赛分别计算、样本不足使用实际场数。球员场均按实际出场数；每90使用所选窗口总分钟。累计分钟门槛仍使用所选GW累计官方样本，避免最近1场被450分钟门槛全部排除。
球队进球、失球、胜率、零封率与联赛积分均按窗口重算；球员官方场均和每90同理。短期窗口不提供仅有赛季累计来源的xG、xPts、偏差和持有率，不拿全部数据冒充最近几场。切换时无效坐标轴自动回到官方基础指标。导出图片注明所选范围，加载失败可重试。
